# Bilayer plotting parameters

Place the following `.npy` files here:

- `tb_WSe2.npy` — 43 monolayer TB parameters for WSe2
- `tb_WS2.npy` — 43 monolayer TB parameters for WS2
- `interlayer_G.npy` — dict with keys: w1p, w1d, w2p, w2d (eV), Vg (eV), phiG (rad)
- `interlayer_K.npy` — dict with keys: Vk (eV), phiK (rad)

These files are exported from the fitting pipeline scripts.
